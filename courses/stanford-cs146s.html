Overview ​

CS146S كورس في Stanford بيدرّس إزاي تطوّر software مع الـ AI coding agents في كل المراحل، مش بس كتابة الكود. المدرّس Mihail Eric، والمحاضرات يوم التلات والخميس [cs146s2026]. الـ slides الأولى بتقدّم الكورس على إنه "about principles not tools"، ومعمول لـ "fairly experienced engineers" عايزين يبقوا "10x engineers" [cs146s-0922].

الصفحات هنا مبنية على الـ study notes بتاعتك عن إصدار Fall 2026 (عناوين المحاضرات بتطابقه، مش Fall 2025)، واتراجعت على الـ slides والـ transcripts الرسمية المنشورة على موقع الكورس.

Lecture order differs from the notes files

الملف week2.md في الـ notes فيه تلات محاضرات، وأولهم (الـ agent harness، يوم 2026-09-24) في الحقيقة تبع Week 1 في الـ syllabus. الترتيب هنا بيتبع الـ syllabus الرسمي.

Learning objectives ​

في آخر الأسبوعين اللي اتغطوا لحد دلوقتي، المفروض أكون قادر:

  • أبني coding agent من الصفر وأشرح كل سطر فيه.
  • أشرّح أي coding agent harness لمكوناته وأعرف كل مكون بيكلّف إيه من الـ context.
  • أطبّق workflow منظم (RePPIT) على مهام في codebases كبيرة، وأختار الـ process المناسب لحجم المهمة.
  • أصمم MCP servers مناسبة للموديلات، وأقيّم code mode بشكل نقدي.
