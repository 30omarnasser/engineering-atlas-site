Agent Instruction Files (AGENTS.md, CLAUDE.md) ​

ReviewedPublishedAI-assisted

Markdown files in a project that a coding-agent harness finds and injects into the model's context, so project rules, architecture, and commands don't have to be repeated in every prompt.

Also known as
AGENTS.md, CLAUDE.md, project instructions, agent configuration files, memory files

Definition ​

Definition: Agent instruction file

ملف Markdown عادي في المشروع، الـ harness بتاع الـ coding agent بيلاقيه ويحقن محتواه في الـ context بتاع الموديل، عشان قواعد المشروع والـ architecture وأوامر التشغيل والاختبار ماتتكتبش من الأول في كل prompt. المحاضرة بتسميه "the user-controlled counterpart to the system prompt" [cs146s-0924, 44:22].

زي ما README.md بيشرح المشروع للبشر، AGENTS.md بيشرح للـ agent يشتغل إزاي جوه المشروع.

Learning objectives ​

  • تفرّق بين الـ system prompt وملفات التعليمات وملفات الـ skills.
  • تعرف مين بيقرا الملف فعلًا، وإمتى، وبأي ترتيب، في Codex وClaude Code.
  • تكتب ملف تعليمات قصير ومفيد، وتعرف إيه اللي مايتحطش فيه.
  • تختار بين AGENTS.md وCLAUDE.md حسب الأدوات اللي بتستخدمها.

Intuition ​

الملف ده زي ورقة "اقرأني الأول" على مكتب موظف جديد: "المشروع FastAPI، الـ tests بـ pytest، ماتلمسش الـ database schema من غير موافقة". الموظف لازم يقراها عشان تفرق. والمسؤول إنه يحط الورقة قدامه هو الـ harness، مش الموديل.

Formal explanation ​

Who reads the file ​

الموديل مابيفتحش الملف لوحده. الـ harness هو اللي بيدوّر على ملفات التعليمات، ويقراها، ويحطها في الـ context. في الـ trace اللي اتعرض في المحاضرة، محتوى CLAUDE.md كان متحقن جوه نفس الـ user block بتاع أول رسالة، تحت "system reminder"، ومعاه جملة بتقول إن التعليمات دي override الـ default behavior [cs146s-0924, 46:09].

AGENTS.md: an open format ​

AGENTS.md بقى format مفتوح، ومشرف عليه دلوقتي الـ Agentic AI Foundation تحت الـ Linux Foundation [agentsmd]. في OpenAI Codex:

  • فيه ملف global في ~/.codex (أو CODEX_HOME): Codex بيقرا AGENTS.override.md لو موجود، وإلا AGENTS.md [codex-agentsmd].
  • في المشروع: بيبدأ من الـ project root (غالبًا الـ Git root) ونازل لحد الـ working directory، ملف واحد من كل folder [codex-agentsmd].
  • الملفات الأقرب للـ folder الحالي بتغلب، لأنها بتظهر متأخر في الـ prompt المجمّع [codex-agentsmd].
  • فيه حد أقصى للحجم (project_doc_max_bytes، الافتراضي 32 KiB) [codex-agentsmd].

CLAUDE.md: Claude Code's own system ​

Claude Code بيقرا CLAUDE.md من أماكن متعددة: ~/.claude/CLAUDE.md للتعليمات الشخصية في كل المشاريع، و./CLAUDE.md أو ./.claude/CLAUDE.md للمشروع، و./CLAUDE.local.md للتعليمات المحلية بتاعتك. وبيدعم @path/to/file لاستيراد ملفات تانية، وملفات في .claude/rules/ ممكن تتربط بمسارات معينة عن طريق paths في الـ frontmatter [cc-memory].

وبخصوص AGENTS.md: قراية AGENTS.md مباشرة محتاجة Claude Code v2.1.277 أو أحدث، وبالـ default بيقراه بس لو مفيش CLAUDE.md (ولا .claude/CLAUDE.md ولا CLAUDE.local.md) في الـ working directory أو أي folder فوقه؛ يعني حتى CLAUDE.local.md شخصي بيخلّي AGENTS.md مايتقراش. الإعداد ده ممكن يتغير بحيث يقرا الاتنين، والـ docs لسه بتنصح بـ import @AGENTS.md جوه CLAUDE.md للجلسات اللي مابتقراش AGENTS.md مباشرة. وAGENTS.override.md مش بيتقري خالص في Claude Code [cc-memory].

المحاضرة لخصت نفس القصة بشكل غير رسمي: الكل كان متفق على AGENTS.md ما عدا Anthropic، وبعدين انضموا من كام أسبوع، والاتنين عمليًا نفس الحاجة؛ وممكن تعمل symlink بينهم [cs146s-0924, 42:44].

Technical example ​

مشروع بيستخدم Claude Code وCodex مع بعض. القواعد المشتركة في AGENTS.md:

markdown
# Project instructions

## Architecture
- Backend: FastAPI; database: PostgreSQL; cache: Redis.

## Rules
- Follow the existing structure in agents/ and memory/.
- Never change the database schema without approval.

## Commands
- Tests: `pytest tests/`

وCLAUDE.md بيستورده ويضيف حاجات خاصة بـ Claude بس:

markdown
@AGENTS.md

# Claude-specific
- Use plan mode before architectural changes.

كده القواعد مكتوبة مرة واحدة، والأداتين بيقروها [cc-memory].

Limitations and common misconceptions ​

An instruction is not a capability

لو كتبت "ابحث على الإنترنت قبل ما ترد" في AGENTS.md والـ agent مفيهوش أداة web search، مش هيحصل حاجة. الملف بيقول للـ agent يستخدم قدراته الموجودة إمتى وإزاي؛ مابيدّيهوش قدرات جديدة.

  • "The file guarantees behavior." التعليمات context، مش كود. الموديل ممكن يتجاهل أو ينسى قاعدة، خصوصًا في جلسة طويلة. لو قاعدة لازم تتنفذ كل مرة (زي "شغّل الـ formatter")، الـ hook أضمن.
  • "Longer is better." الملف بيتبعت في كل request، فكل سطر فيه بيدفع من الـ context. وCodex نفسه بيقطع بعد 32 KiB بالـ default [codex-agentsmd].
  • "All tools read it the same way." لأ: Codex بيجمع من الـ root لحد الـ working directory، وClaude Code بيفضّل CLAUDE.md ومابيقراش AGENTS.override.md [codex-agentsmd; cc-memory].
  • "Edits apply immediately." بيتقرا غالبًا في بداية الجلسة؛ لو عدلته في نص جلسة، ابدأ جلسة جديدة عشان تتأكد إنه اتقرا. (ملحوظة عامة، والتفاصيل بتختلف حسب الأداة.)

Exercises ​

Exercise: Write a ten-line AGENTS.md

اكتب AGENTS.md لمشروع من مشاريعك في 10 سطور بالكتير: architecture، وأوامر الـ tests، وتلات قواعد أمان. وبعدين اسأل نفسك عن كل سطر: لو شلته، الـ agent هيغلط؟

Solution

السطور اللي إجابتها "لأ" (زي "write clean code") شيلها؛ الموديل هيعملها كده كده، وهي بتاكل context. خلي السطور اللي فيها معلومة الموديل مايقدرش يخمنها: أوامر بعينها، وحاجات ممنوعة، وأماكن ملفات.

Exercise: Predict what Claude Code loads

مشروع فيه AGENTS.md في الـ root، ومفيش CLAUDE.md في المشروع، بس فيه ~/.claude/CLAUDE.md عندك. Claude Code (إصدار حديث بالإعدادات الافتراضية) هيقرا AGENTS.md؟

Solution

أيوه. الـ default بيقرا AGENTS.md لو مفيش CLAUDE.md في الـ working directory أو فوقه، والـ docs بتقول إن ~/.claude/CLAUDE.md مش بيتحسب في الشرط ده [cc-memory].

Key takeaways

  • الـ harness هو اللي بيلاقي ملفات التعليمات ويحقنها؛ الموديل مابيفتحهاش.
  • AGENTS.md format مفتوح ومشترك؛ CLAUDE.md خاص بـ Claude Code وبيقدر يستورد AGENTS.md.
  • التعليمات context مش ضمان، ومش قدرات.
  • قصير ومحدد أحسن من طويل وعام، لأنه بيتبعت في كل request.

Review questions ​

  1. ليه المحاضرة بتوصف CLAUDE.md بإنه "user-controlled counterpart" للـ system prompt؟
  2. في Codex، لو فيه AGENTS.md في الـ root وواحد في backend/، وإنت شغال جوه backend/، مين بيغلب وليه؟
  3. إمتى تحط قاعدة في AGENTS.md، وإمتى في skill، وإمتى في hook؟
  4. إيه أسهل طريقة تخلي مشروع واحد يشتغل مع Claude Code وCodex من غير تكرار القواعد؟
